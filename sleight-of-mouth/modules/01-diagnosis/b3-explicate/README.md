# b3-explicate — экспликация

Уточняющие вопросы по осям причин: подтверждает уязвимости (`▲` → `▲▲`), поднимает мишень I, раскрывает неполные формулировки до полной. Выход блока — выход модуля: заполненная карта, готовая для `02-intervention`.

Заметка-протокол: [explicate.md](explicate.md) — инструмент (четыре вопроса-причины, с. 122–125), две работы (подтверждение с правилом трёх исходов; раскрытие неполных перебором осей до первой связки), порядок вопросов, покрытие мишеней I–V, прецеденты. Схема-референс: [alg-explicate.drawio](alg-explicate.drawio). Диалог ведёт **интервьюер** — роль исполнителя с тремя реализациями (модель-скилл, модель-приложение, человек по документам): [interviewer.md](interviewer.md).

Решения 2026-09-05: три исхода ответа — содержательный и неспособность ответить подтверждают (`▲▲`, неспособность — сильнее, гл. 8, с. 167; гл. 5, с. 96), отказ — «ответ не получен»; порядок — неполным все четыре оси до первой связки (приоритет C-E, наследие [implicit](../b1-parse/implicit/implicit.md)), полным — мишень I (ось по типу: C-E → «Что заставляет…?», CEq → «Что значит…?»), затем по `▲` в порядке полей; мишень I поднимается сразу подтверждённой; III — без своего вопроса-причины (попутно), V — экспликацией допущений (гл. 8, с. 174).

Алгоритмы: по наполнению (`alg-*.md`).
