# Интервьюер — роль исполнителя диалога

Сторона, ведущая диалог с носителем убеждения по протоколу модуля. Единственная сущность библиотеки, которая говорит с человеком: b1 и b2 работают с текстом, диалоговые шаги всегда ведёт интервьюер. Первый протокол — [экспликация](explicate.md) (b3); та же роль будет вести и серию применений в [02-intervention](../../02-intervention/README.md) — перепроверка после каждого применения тоже диалог, а диагностический вопрос по канону §5.6 сам есть паттерн.

Разделение ответственности: **протокол** ([explicate.md](explicate.md)) определяет, какие вопросы задаются, в каком порядке и что каждый ответ значит для карты; **интервьюер** спрашивает и фиксирует. Правил толкования у интервьюера нет: любой ответ проходит через правила протокола; неоднозначный ответ — уточняющий вопрос, не догадка.

## Реализации

Три равноправные реализации, протокол один:

| Реализация | Где | Что меняется |
|---|---|---|
| Модель-скилл | диагностическая сессия как слэш-команда | только обёртка |
| Модель-приложение | `app/` (прикладная фаза) | только обёртка |
| Человек | работа по документам волта: самопомощь или пара «исследователь ↔ носитель» | документы и есть инструкция |

Инвариант: скилл, приложение и человек с карточками ведут сессию одинаково — по одному протоколу. Для модельных реализаций интервьюер — системный промпт, собранный из пары «протокол + эта карточка»; тест тот же, что у алгоритмов: модель обязана воспроизводить прецеденты протокола (как прогон по [examples.md](../b1-parse/examples.md) у b1).

## Контракт (инварианты поверх реализаций)

1. Задаёт только вопросы протокола — не импровизирует свои.
2. Выбор и порядок вопросов — по правилам протокола: неполное — полный проход осей до первой связки; полное — мишень I (ось по типу), затем по `▲` в порядке полей.
3. В карту пишет только поля экспликации (`▲` → `▲▲`, подъём I, тип у неполных, звенья) — мишени сам не ставит и не снимает, карту не переразбирает.
4. Исходы ответов различает по правилу трёх исходов протокола: содержательный → `▲▲`; неспособность ответить → `▲▲` (сильнее); отказ → «ответ не получен».
5. Побочный сдвиг фиксирует честно как результат (канон §5.6: «Как узнаёшь?» = №10) — не скрывает и не выдаёт за ошибку.
6. Тон книги, с. 139: «не в том, чтобы порицать или унижать человека за ограничивающие убеждения, а в том, чтобы помочь ему расширить и обогатить его „карту мира“» — вопросы-исследование, не конфронтация и не допрос.
