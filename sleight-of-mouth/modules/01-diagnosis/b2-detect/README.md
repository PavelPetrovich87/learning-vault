# b2-detect — детекция

Ищет во фразе маркеры уязвимости и ставит отметки мишеням I–V. Каждая `▲` обеспечена находкой — маркер реально стоит во фразе.

Заметка блока: [detect.md](detect.md) — вход (карта после b1, включая неполные; поле `фраза` — материал уровня фразы), понятие «уязвимость» в терминах гл. 8, алгоритм (шаги 1–4). Словарь маркеров (канон): [markers.md](markers.md) — 8 карточек с цитатами книги. Схемы: [vulnerability.drawio](vulnerability.drawio) · [alg-detect.drawio](alg-detect.drawio).

Соответствия (стартовый набор, канон §4):

- кванторы общности («все», «всегда», «никогда»…) → II;
- обесценивающее «но» → IV;
- монолитный ярлык («всё или ничего») → III;
- один эпизод = вся жизнь, размытая верификация → IV.

Ноль находок — тоже результат: карта без уязвимостей.

Алгоритмы: по наполнению (`alg-*.md`).
