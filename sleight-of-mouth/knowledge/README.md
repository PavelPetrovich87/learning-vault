# База знаний «Фокусы языка» (Robert Dilts, Sleight of Mouth)

Структурированная база знаний по книге Р. Дилтса **«Фокусы языка. Изменение убеждений с помощью НЛП»** (СПб.: Питер, 2010; оригинал *Sleight of Mouth*, Meta Publications, 1999), подготовленная для использования ИИ-агентами и как основа будущего приложения по коррекции убеждений.

- Источник: `Дилтс Р.-Фокусы языка…2010.pdf` (256 стр., русский перевод)
- Формат: Markdown + YAML-frontmatter + машинные индексы (`index.json`, `examples/corpus.jsonl`)
- Охват: вся книга — концепции гл. 1–4, теория убеждений гл. 5–6, процессы и состояния гл. 7–8, каталог 14 паттернов гл. 9, приложение и заключение

## Как читать базу

**Для LLM-агента:** загружать файлы по необходимости через `index.json`; YAML-заголовок каждого файла содержит id, тип, связи (`related`) и ссылку на источник (глава/страницы книги). Цитаты краткие, всё остальное — структурированный пересказ.

**Для приложения:** паттерны — атомарные единицы: имя, определение, ключевой вопрос-вопросник, примеры (убеждение → реплика). Корпус `examples/corpus.jsonl` — пары (belief → response) с привязкой к паттерну и странице источника.

## Кратчайший маршрут для нового агента

1. `../research/composition-model.md` — закреплённая рабочая схема проекта (термины, мишени, правила компоновки).
2. `patterns/overview.md` — что такое система паттернов.
3. `beliefs/belief-structure.md` — из чего состоит убеждение (CEq / C-E).
4. `patterns/<id>.md` — конкретный паттерн при выборе вмешательства.
5. `processes/exercises.md` §25 — бланк применения всех 14 вопросов.
