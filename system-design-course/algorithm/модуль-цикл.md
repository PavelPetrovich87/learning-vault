# Модуль ЦИКЛ — карта цикла: шаги 1–2 ✅, шаги 3–6 ⬜

> Заметка-модуль алгоритма [[Алгоритм выбора решений]] · диаграмма: `карта-алгоритма.drawio` (рядом)
> Спецификации шагов — в папке `цикл-шаги/`, по заметке на шаг (шаги 1–2 — [[шаг-1-состав]], [[шаг-2-бюджеты-ролей]]; заметки шагов 3–6 заводятся по мере гриллинга). Синхронизация: правка шага = его заметка ×2. У Цикла состояние внешнее — живёт в модели.

**Назначение.** Исполнение: шесть шагов. Модификация состава — только шаг 1.

**Роль: проектировщик (не модуль).** Процессор алгоритма: исполняет шаги — на бумаге, в голове, в инструменте, носитель безразличен. Две наружные функции: **переговорщик** (ходит с вопросами из реестра вопросов к владельцам чисел; единственные доступные операции — уточнение и торг) и **консервативный владелец** (пока ответа нет, подставляет предположение и сам «держит» число). Точка входа/выхода: реестр вопросов → наружу, уточнение/торг → обратно в рамку.

**Симметрия цикла.** Шаги 1/3/5 назначают исполнение (лестница роль → класс → продукт), шаги 2/4/6 проверяют и готовят (2 — развеска чисел, 4 — профили, 6 — испытание).

**Петли.** Внутренняя (модификация состава → пересчёт реестров → чтение), возвраты 2→1 / 3→1 / 6→1, вверх (торг), во времени (мониторинг после запуска — тема 6.1).

## Шаги

| # | Шаг | Ступень | Кратко | Статус |
|---|---|---|---|---|
| 1 | [[шаг-1-состав]] | РОЛЬ | очередь из модели (уже отсортирована) → кластер → цепочка минимальных ролей → модификация состава; единственный писец состава | ✅ прогрилован |
| 2 | [[шаг-2-бюджеты-ролей]] | — | общие числа рамки → бюджеты ролей; у роли появляется своя цифра для отбора кандидатов. Не влезает → шаг 1 | ✅ прогрилован (у шага — конвейер чисел и подалгоритмы П1–П5) |
| 3 | Кандидаты | КЛАСС | классы решений, применимые к паттернам роли. Пустое множество → форма роли неверна → шаг 1 | ⬜ черновик |
| 4 | Профили | — | даёт / стоит / ломает — матрица по всем НФТ, не по своей ветке; отказы на стыках видны только на пакете; линзы SAM на каждом кандидате | ⬜ черновик |
| 5 | Выбор | ПРОДУКТ | пакетно, со стыками; из проходящих — простейшее (KISS) | ⬜ черновик |
| 6 | Испытание | — | цепочка «решение → число (Литтл, нагрузка на роли) → отказ»; kill-test; проверочные сценарии. Провал → новая версия состава | ⬜ черновик |

**После запуска:** мониторинг сверяет систему с теми же цифрами (тема 6.1) — петля во времени.
