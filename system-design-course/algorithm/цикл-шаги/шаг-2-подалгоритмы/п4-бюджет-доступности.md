# П4 «Бюджет доступности» — подалгоритм шага 2

> Подалгоритм шага 2 [[шаг-2-бюджеты-ролей]] · обзор конвейера: [[шаг-2-конвейер.drawio]] · термины: [[словарь]] · диаграмма: [[п4-бюджет-доступности.drawio]]

**Назначение.** Раздаёт девятки доступности ролям пути — правило «+1 девятка» на примерных расчётах.

**Вход (откуда).**

- SLO доступности (поле 3): например ≥ 99% за месяц — две системные девятки.
- Пути из П2 — какие роли на каждом пути.

**Алгоритм.**

1. Посчитать системные девятки (99% → две).
2. Каждой роли пути — на одну девятку больше системной, одна для всех: 99% → 99.9%. Умножение идёт один раз по всему пути (позиция в цепочке не важна, множители равноправны), запаса хватает до ~10 ролей (0.9999¹⁰ ≈ 99.9%).
3. Роль на нескольких путях берёт самое строгое из требований.
4. Проверка сборки: произведение ≥ SLO: 99.9% × 99.9% ≈ 99.8% ≥ 99% ✓.

**Выход (куда).** `бюджеты_ролей` доступность (роль · требуемое · выведено_из). Точная развеска произведением ровно по SLO (99.95% × 99.95% ≈ 99.9%) — исполнениям «расчёт» и «прогон».

**Типичные провалы.**

- Девятки по уровням: умножили на каждом этаже цепочки — задвоение запаса.
- Забытая роль пути: произведение считается по всем участникам.
- Смешение качеств: мс и девятки не обмениваются — только через цену кандидатов (шаги 4–5) или торг.
