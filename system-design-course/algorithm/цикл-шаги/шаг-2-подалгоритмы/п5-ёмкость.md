# П5 «Ёмкость» — подалгоритм шага 2

> Подалгоритм шага 2 [[шаг-2-бюджеты-ролей]] · обзор конвейера: [[шаг-2-конвейер.drawio]] · термины: [[словарь]] · диаграмма: [[п5-ёмкость.drawio]]

**Назначение.** Считает одновременность: сколько запросов роль обязана держать — слоты; кратность шага 1 проверяется числом копий.

**Вход (откуда).**

- λ на роль из П2 (роль · сценарий).
- Фазы из П3 / справочник: своя фаза + ожидания подчинённых ролей.

**Алгоритм.**

1. W — время слота: воркер держит слот и пока синхронно ждёт подчинённую роль (обработчик ждёт хранилище) → W = своя фаза + ожидания.
2. Слоты = λ × W (Закон Литтла), план при загрузке ≤ 70–80 % — у порога взрывается хвост.
3. Разложить слоты по копиям: сколько копий роли реально нужно. Пример: приёмник 18 × 0.01 ÷ 0.75 < 1 слота на копию → пул ×2 подтверждён; хранилище 7 × 0.35 ÷ 0.75 ≈ 4 слота.

**Выход (куда).** `ёмкость` (слоты на роль; кратность шага 1 подтверждена числом или запрошена новая — через боль, шагом 1).

**Типичные провалы.**

- Впритык: план ёмкости при загрузке → 100 % — хвост взрывается ещё до отказа.
- W без ожиданий: только своя фаза — слотов занижено.
- Слоты из средней λ без пика.
