# Модуль СПРАВОЧНИК — ✅ прогрилован (раунд 4)

> Заметка-модуль алгоритма [[Алгоритм выбора решений]] · диаграмма: `карта-алгоритма.drawio` (рядом)
> Шаблон спецификации: Назначение / Контракт / Входы–выходы (API) / Содержимое / Границы / Рендеры.

**Назначение.** Универсальные порядки величин: латентности RAM/SSD/сети, объёмы, скорости. Общая физика домена, не проектные данные. Рамка — аргументы вызова (свои у каждого проекта), справочник — стандартная библиотека (одна на все запуски).

**Контракт.** Read-only. **Операций нет:** со скоростью SSD не торгуются и её не уточняют — читают как есть; выбрать другое железо — кандидат на шаге 5, не правка справочника. Точность — порядок величины (×10), не точное число; контракт один: «дай порядок».

**Содержимое.** Таблицы латентностей (RAM ~0,1 мс; SSD ~1 мс; сеть в регионе ~5–20 мс; межконтинент ~100–300 мс), объёмы, скорости. Расширяется по мере прохождения глав.

**API.** Lookup по типу запроса. Потребители: оценщик (исполнение «примерные расчёты»), шаг 2 (бюджеты), шаги 4–5 (профили кандидатов).

**Граница с рамкой.** Число зависит от фактов проекта (география пользователей, наш ЦОД) → рамка, поле «параметры нагрузки»; универсально → справочник.

**Рендеры.** Таблица в голове (интервью) · приложение к RFC · lookup инструмента · поиск ИИ-агента. Взаимозаменяемы — тот же паттерн, что у оценщика: структура не зависит от носителя.
