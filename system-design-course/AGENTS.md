# system-design-course — Agent Guidelines

Конспекты глав учебника **System Design Trainer** (репозиторий `~/learning/учебники/system-design`).

## Назначение

Один файл = одна глава курса. Рабочий конспект для прохождения заданий: определения в формулировках книжных якорей, таблицы, mermaid-диаграммы, ловушки, связи. Русский язык (working zone); термины дублируются английскими.

## Правила

1. **Источник истины — `chapters/chapter-N-M/content.md` в репозитории курса.** Конспект — дистилляция, не пересказ целиком. Обновляется агентом после приёмки главы (статус в frontmatter: `implemented` = глава принята, `experimenting` = в работе).
2. **Формулировки — из книжных якорей** (Сюй/Клепманн), не «своими словами по памяти». Синтез курса помечать 🟡/🔴 как в оригинале.
3. **Спойлер-дисциплина проектных глав:** референсы сравнения (например, [С1] гл.12 для 1.6) не попадают в конспект до приёмки RFC пользователя.
4. Frontmatter: `status`, `chapter`, `module`, `anchor`, `created` (+ `updated` при правках).
5. Структура файла: якорь → ключевые идеи → таблицы/диаграммы → формулы → ловушки → глоссарий → «Связано» (wiki-links на соседние главы и английские evergreen-заметки).
6. Карта глав и связей — `INDEX.md`; модульные подпапки `module-N/`.
7. Флеш-карты здесь **не** создаются — их дом `System Design interview/flash_cards/` (deck `#flashcards/system-design`).
8. **`algorithm/` — живая теория совместного мышления** (не конспекты глав): универсальный алгоритм выбора решений, grilling-сессии пользователя с агентом вне рамок упражнений. Канон — `algorithm/` в репозитории курса; эта папка — зеркало. Структура (одинакова в обеих копиях): **README-карта** (замысел, диаграмма, указатель, журнал) + **заметки модулей** `модуль-рамка` / `модуль-справочник` / `модуль-модель` / `модуль-цикл` + **`словарь.md`** (дисциплина языка: термины вводятся в нём, модули пользуются только ими) + **`карта-алгоритма.drawio`**. Синхронизация: правка модуля = его заметка ×2; правка карты = README ×2 + drawio ×2; правка языка = словарь ×2.
9. **`references/` — справочники-шпаргалки** (не конспекты глав и не канон алгоритма): тренировочные каталоги по заказу пользователя; синтез из материалов курса + внешних источников (обязательны ссылки, расхождения источников фиксируются). Подпапка = тема; первая — `сборка-рамки/` (уточняющие вопросы интервью по типам приложений). Не обновляются автоматически после приёмки глав — только по запросу.
