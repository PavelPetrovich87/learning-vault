# FSD — уровни построения проекта

> Шесть папок-уровней: как FSD-проект растёт от минимума (`shared + pages + app`) до кросс-импортов и миграции легаси. Каждый уровень = **статья** (семантика по главе 1.2 + цитаты официального скилла) + **алгоритм** (draw.io, по decision framework скилла) + **3 примера** от простого к сложному (draw.io: дано → шаги → итог с кусками кода).
> Обзор всей таблицы кейсов одним экраном — [[FSD — кейсы размещения (шпаргалка)]]. Анатомия самого скилла (чтобы адаптировать под свои задачи) — [[Анатомия скилла feature-sliced-design]].

## Позвоночник (сквозной порядок вопросов)

Это decision framework скилла (SKILL.md §2), один на все уровни:

1. **Шаг 1.** «Where is this code used?» — одна страница → её слайс; дублирование между страницами допустимо.
2. **Шаг 2.** Инфраструктура без бизнес-логики? → `shared/` (ui / lib / api / config / auth).
3. **Шаг 3.** Полное пользовательское действие у нескольких потребителей? → `features/`.
4. **Шаг 4.** Бизнес-доменная модель у нескольких потребителей? → `entities/`.
5. **Шаг 5.** Конфигурация всего приложения? → `app/`.
6. **Golden Rule:** «When in doubt, keep it in `pages/`.» (Сомневаешься — оставляй в pages.)

Уровни этой папки — те же шаги, развёрнутые в порядок роста проекта.

## Карта скилла: когда агент какой файл грузит

Скилл построен на progressive disclosure: агент читает только `SKILL.md`, reference-файлы — по ситуации (SKILL.md §10):

- `layer-structure.md` — реорганизация существующих папок, состав слоя/слайса, layout страниц, группы слайсов → **уровень 6**
- `growth-walkthrough.md` — новый проект с нуля, «как структура заслуживает слои» (магазин в 4 снапшотах) → **уровни 2–4**
- `cross-import-patterns.md` — кросс-импорты, `@x`, выбор стратегии A/B/C/D → **уровень 5**
- `excessive-entities.md` — создавать/удалять entity, пропуск слоя entities, CRUD → **уровень 3**
- `asset-handling.md` — картинки, иконки, шрифты, PDF → **уровень 1**
- `migration-guide.md` — v2.0 → v2.1, non-FSD → FSD → **уровень 6**
- `framework-integration.md` — роуты, proxy, алиасы (Next.js, React Router, Nuxt, Vite, Astro) → **уровень 6**
- `auth-and-api.md` — токены, login flow, DTO, request-функции → **уровень 1** (+ 3)
- `state-management.md` — Redux, TanStack Query → уровень 4 (по мере надобности)
